# FACILITRACK

Integrated mobile and web-based school facility issue reporting and
maintenance monitoring system for Cavite State University - Imus Campus.

- `backend/` NestJS + Prisma + PostgreSQL API
- `web/` React + TypeScript coordinator dashboard
- `mobile/` Flutter app (reporters and technicians)

Create `backend/.env` with `DATABASE_URL` and `JWT_SECRET` before running.
